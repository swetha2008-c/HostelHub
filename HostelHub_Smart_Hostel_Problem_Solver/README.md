# HostelHub – Smart Hostel Problem Solver

A professional, responsive hostel complaint-management web app built using only HTML5, CSS3 and vanilla JavaScript.

## Features
- Problem reporting form
- Smart triage and priority detection
- Complaint dashboard with status tracking
- LocalStorage persistence
- Demo complaints
- Smart category suggestions
- Emergency help center
- Analytics and most-reported category
- Responsive mobile/desktop design

## Run
Open `index.html` in any modern browser. No backend or installation is required.

## Hackathon note
The dashboard starts with sample/demo complaints so the presentation looks realistic. New complaints are stored locally in the browser.
